Technical decisions · v0.1.0

The choices that
carry Shelf.

Nine decisions about identity, sync, hosting and rendering — and the cost each one accepts.

docs/DESIGN.md in TyrellD1/shelf

The spine

Local bytes are the truth; every map is derived.

`~/.shelf/html/<machine>/<path>` holds the documents. `index.json` is a cache of metadata that can be deleted and rebuilt by scanning the store.

Authority

One writer, three readers, no second opinion.

Both front ends read through the same process boundary, which is why they never disagree about what is on the shelf.

Identity

Ids are derived, not assigned.

fileId(machine, path) =
  "sf_" + sha1(machine + "\0|" + path).slice(0, 20)

fileId("mac-mini", "q3.html")
  → sf_7c2b1e9f0a4d6b8c3a5e

What that buys

A local store that lost its index reconstructs the same ids the server already knows. shelf read <id> works from any machine.

The server recomputes the id and rejects a mismatch, so a client cannot address another path's row.

sha1 here is a naming hash, never content integrity — that is sha256.

Decisions

Each choice buys one property and costs one thing.

DecisionBuysCosts
Immutable paths (-v2, -v3)Every version stays addressable; sync rows never change identityThe shelf grows; names get suffixes
sha256 content addressingRe-runs are no-ops; a failed sync only moves what changedHashing on every write
Cursor sync on server edited_atNo client clocks, no lost deltas, plain SQLOne wall clock lives in the database
CLI as the only store implementationTerminal and window can never disagree~60 ms process spawn per read
Single-user allowlist authNo sharing, roles, or invitation surfaceNot usable by anyone else as-is

Rendering

Artifacts may run code, but never reach the network.

default-src 'none'the whole policy for a local documentscript-src and style-src allow 'unsafe-inline' only

Desktop: the reader iframe points at shelf://localhost/view/<id>. The Rust handler runs shelf read and returns the bytes with that header.

Phone: the PWA renders the same document from an object URL inside a sandboxed iframe with an opaque origin.

Works

Inline scripts, inline styles, data: and blob: images, own localStorage on desktop.

Blocked

CDNs, remote fonts, beacons, fetch, form posts, base URLs, and new Function — unsafe-eval is deliberately absent.

A document that needs the network is a document that must inline its dependencies instead.

Hosting

Cheap, programmable, and boring to operate.

Cloudflare Worker

One deployed unit serves the API, the auth pages and the PWA. Deploy is one command; there is no server to patch.

Postgres on Neon

One table, one text column for the HTML, capped at 5 MB per document.

Hyperdrive in front

Production uses pg over a pooled connection; local dev uses the same driver against a local Postgres, so both paths run identical SQL.

Push-back on the brief: Cloudflare D1 would remove a vendor and a config step. Postgres was kept because the data is worth more than the convenience.

Alternatives

What was considered and rejected.

RejectedWhy not
SQLite for the local mapHundreds of small files; a JSON map is milliseconds and keeps the CLI dependency-free. The store.ts boundary is where it would change.
Device-code auth (RFC 8628)Works over SSH, but the loopback redirect is one click instead of typing a code — and this is a single-user desktop tool.
Object storage for HTMLSigned URLs, lifecycle rules and a second consistency story, for payloads smaller than a photo.
Embedding the store in the Tauri appTwo implementations of the same rules is how the window and the terminal start disagreeing.
A background sync daemonOut of scope: sync runs on app open, on chip click, or when the agent calls shelf sync.

Evidence

What proves it works today.

35unit tests across ids, paths, flags, index, UI logic
30end-to-end smoke checks against a local Worker + Postgres
2Rust tests for deep links and the CLI-backed reader

The smoke run drives the real browser handoff, writes, versions, replaces, and pulls a file written by a second machine into the local store.

CLI bundles to one 53 KB file with no runtime dependencies beyond Node built-ins.

Limits

Honest gaps, in order of likely annoyance.

  • The desktop bundle is unsigned: first launch needs right-click → Open, or signing with an Apple certificate.
  • No delete or rename — a deliberate consequence of immutable paths, and the first change I would make.
  • Sync is manual, never background.
  • Search is a path ILIKE locally and server-side; full-text is the upgrade at a few thousand documents.
